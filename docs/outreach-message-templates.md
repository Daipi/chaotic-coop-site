# Outreach Message Templates

## Goal

Get the first real mentions and links for `CoopQueue` without spamming people or sending generic SEO mail.

Use these templates as a base.

Do not mass-send them unchanged.

## Rules

- Personalize the first sentence
- Link the page that best matches the context
- Keep the ask small
- Do not oversell "SEO"
- Do not ask for exact-match anchor text

## Best Pages To Pitch First

- `https://coopqueue.com/features/repo-vs-lethal-company/`

## Good Anchor Examples

- `R.E.P.O. vs Lethal Company`
- `games like R.E.P.O.`
- `co-op horror picks for beginners`
- `Discord night game picks`
- `less scary alternatives to R.E.P.O.`

## Bad Anchor Examples

- `best SEO site`
- `cheap SEO traffic`
- `rank #1 repo keyword`
- exact-match repetition across every mention

## Where To Look First

- small gaming blogs
- indie game recommendation sites
- friends with personal blogs or newsletters
- relevant Discord communities with resource channels
- Reddit threads where the page is a direct answer to the question being asked

## First Two-Week Target

Aim for `5-10` real mentions or links, not scale.

Ideal mix:

- `1-2` homepage or brand mentions
- `2-4` comparison-page links
- `2-4` recommendation-page links
