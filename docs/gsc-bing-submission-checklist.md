## Goal

Get the highest-intent `CoopQueue` URLs discovered and indexed first.

Use this checklist for:

- `Google Search Console`
- `Bing Webmaster Tools`

## Before Submitting

- Confirm `https://coopqueue.com/robots.txt` is live
- Confirm `https://coopqueue.com/sitemap-index.xml` is live
- Confirm the canonical on the inspected page points to itself
- Confirm the page is not blocked by `noindex`

## Google Search Console Workflow

For each URL:

1. Open URL Inspection
2. Paste the exact canonical URL
3. Wait for the live check
4. If the page is available to Google, click `Request Indexing`
5. Log the submission date in the tracker
6. Record whether it says:
   - URL is on Google
   - URL is not on Google
   - Discovered, currently not indexed
   - Crawled, currently not indexed

## Bing Webmaster Tools Workflow

For each URL:

1. Open URL inspection or URL submission
2. Submit the same canonical URL
3. Log the submission date in the tracker
4. Record the status if Bing exposes one

## What To Recheck After Submission

Check these every `2-3` days for the first two weeks:

- Homepage indexed or not
- Core comparison pages indexed or not
- Any page moving from "discovered" to "indexed"
- First impressions on submitted URLs

## What Not To Do

- Do not resubmit the same URL every few hours
- Do not submit dozens of low-priority URLs before the core ten
- Do not change titles and intros every day before impression data exists
